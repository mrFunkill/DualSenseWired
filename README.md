# DualSense Wired для Windows

[English](README.en.md)

DualSense, подключённый по **Bluetooth**, виден играм как подключённый **по проводу**: работают
**динамик геймпада**, **HD-вибрация** (тактильная отдача) и **адаптивные триггеры** — в играх,
которые включают эти функции только при проводном подключении (проверено в Marvel's Spider-Man
Remastered, Miles Morales и Helldivers 2).

Это Windows-версия плагина для Steam Deck
[decky-dualsense-wired](https://github.com/mrFunkill/decky-dualsense-wired).

## Возможности

- Виртуальный проводной DualSense со звуковым устройством, как у настоящего геймпада по USB.
  Игры сами выводят на него звуки динамика и HD-вибрацию.
- Звук и вибрация передаются на геймпад по Bluetooth; адаптивные триггеры, подсветка, обычная
  вибрация — тоже.
- Bluetooth-геймпад скрывается от Steam и игр (HidHide), чтобы не было двух контроллеров.
- Настройки: громкость динамика, сила вибрации, буфер звука (задержка / устойчивость),
  включение адаптивных триггеров.
- Раскладка: переназначение и отключение кнопок, смена стиков местами, мёртвые зоны, инверсия
  оси Y правого стика.
- Заряд батареи, предупреждение о низком заряде, значок в трее, автозапуск с Windows.
- Интерфейс на английском и русском (по языку Windows), светлая и тёмная тема.

## Требования

- Windows 11 или Windows 10 2004+ (проверено на Windows 11), x64.
- Bluetooth на ПК, DualSense (DualSense Edge должен работать, но не проверялся).
- Игры с поддержкой звука/HD-вибрации DualSense по проводу.

## Установка

1. Скачайте `DualSenseWired-X.Y.Z-setup.exe` со страницы
   [Releases](https://github.com/mrFunkill/DualSenseWired/releases) и запустите.
2. Установщик поставит, если их нет:
   - [usbip-win2](https://github.com/vadimgrn/usbip-win2) 0.9.8.1 — драйвер виртуального USB-устройства
     (более старые версии заменяются: в 0.9.7.8 есть ошибка, вызывающая BSOD);
   - [HidHide](https://github.com/nefarius/HidHide) — скрывает Bluetooth-геймпад от игр.

   После установки драйверов может понадобиться перезагрузка.
3. Подключите DualSense в настройках Bluetooth Windows (зажмите **Create + PS**, пока подсветка
   не начнёт часто мигать).
4. Запустите DualSense Wired. В Steam должен остаться один DualSense, подключённый «по USB».

Устройством вывода по умолчанию в Windows оставьте колонки или наушники: игры сами находят
динамик геймпада («DualSense Wireless Controller»).

Если запущен DSX, закройте его: два приложения не могут одновременно управлять геймпадом.

## Как это работает

- Приложение запускает USB/IP-сервер с виртуальным DualSense (настоящие USB-дескрипторы:
  HID + звук 4 канала, 48 кГц), а usbip-win2 подключает его в Windows как USB-устройство.
- Отчёты Bluetooth-геймпада переводятся в формат USB и обратно.
- Звук, который игра выводит на геймпад, пересжимается: каналы 1–2 (динамик) — в Opus,
  каналы 3–4 (вибромоторы) — в поток вибрации 3 кГц, и отправляется по Bluetooth.
- Реализация независимая: протокол изучен по поведению собственного геймпада и открытым
  источникам, код сторонних закрытых программ не использовался.

## Ограничения

- Один геймпад одновременно.
- Микрофон и разъём для наушников геймпада по Bluetooth не поддерживаются.
- Действия клавиатуры и мыши в раскладке — в планах.

## Удаление

«Параметры → Приложения → DualSense Wired → Удалить». Приложение остановится и вернёт
Bluetooth-геймпад Steam. usbip-win2 и HidHide удаляются отдельно, если они больше не нужны.

## Сборка из исходников

Нужны .NET 8 SDK и Inno Setup 6.

```powershell
dotnet build DualSenseWired\DualSenseWired.csproj        # приложение (запуск требует прав администратора)
# установщик: положите установщики usbip-win2 и HidHide в installer\deps\ (см. installer\build.ps1)
powershell -ExecutionPolicy Bypass -File installer\build.ps1
```

Журнал работы: `%LOCALAPPDATA%\DualSenseWired\DualSenseWired.log`, настройки:
`%APPDATA%\DualSenseWired\settings.json`.
